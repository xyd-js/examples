# macOS

macOS is Apple's desktop operating system for Mac computers, built on the
Darwin kernel with a Unix userland.

## The platform

Tight hardware/software integration on Apple silicon delivers strong
performance-per-watt; Homebrew is the de-facto package manager.

## For developers

Xcode, Instruments, and the only sanctioned toolchain for building iOS,
iPadOS, and watchOS apps.
