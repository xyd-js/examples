# Java

Java is a class-based, object-oriented language designed for portability —
write once, run anywhere on the JVM.

## The JVM

A mature virtual machine with world-class JIT compilation and garbage
collectors, also hosting Kotlin, Scala, and Clojure.

## Where it shines

Large-scale backend systems, Android development, and enterprise software
that must run for decades.
