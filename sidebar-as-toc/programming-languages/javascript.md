# JavaScript

JavaScript is the language of the Web — every browser ships it, and Node.js,
Deno, and Bun bring it to servers and tooling.

## The ecosystem

npm is the largest package registry in the world; TypeScript adds static
types on top of the language and compiles away.

## Everywhere

From interactive UIs to serverless functions, CLIs, and even embedded
runtimes.
