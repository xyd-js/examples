# Examples repo

## After changing examples, update `examples-build`

The showcase site for these examples is built from a **separate, private repo
(`examples-build`)**. After you add, rename, remove, or re-describe an example
here, go update that repo too — otherwise the change won't show up on the site.

## Conventions

- Commit style: `feat(examples): <slug>` for new examples.
- Do NOT add `Co-Authored-By: Claude` or any AI attribution to commits.
