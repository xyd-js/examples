# Sessions API

The reference pages in this section are generated from
`sessions-api.xsdk.yaml` — an OpenAPI spec that **carries its own SDK docs**
as `x-sdk` extensions (embedded upstream with `xyd opensdk xsdk`). Notice
that `docs.json` has **no `sdk` flag**: xyd detects `x-sdk` in the spec and
renders SDK-native docs from it directly.

The default view is the raw **HTTP/cURL** one; pick a language in the
code-sample switcher and the method signature, the Parameters/Returns types,
and the usage sample all switch together. Your choice persists as you browse
between operations.
