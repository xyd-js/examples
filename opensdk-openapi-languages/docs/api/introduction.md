# Sessions API

This example restricts the SDK docs to **TypeScript and Python** only:

```json
{ "source": "./sessions-api.yaml", "route": "docs/api", "sdk": { "languages": ["typescript", "python"] } }
```

The language switcher on the reference pages offers just those two SDKs plus
the raw **Shell** (HTTP/cURL) view — which is also the default view.
