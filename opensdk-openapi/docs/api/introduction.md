# Sessions API

The reference pages in this section are generated from `sessions-api.yaml` —
with `"sdk": true`, every operation carries **SDK-native docs** on top of the
classic reference. The default view is the raw **HTTP/cURL** one; pick a
language in the code-sample switcher and the method signature, the
Parameters/Returns types, and the usage sample all switch together.

Your choice persists as you browse between operations.
