# About the MCP reference

:::subtitle
Auto-generated API reference for the connected MCP server.
:::

The pages in this section are generated from the MCP server's
`tools/list` and `resources/list` endpoints at build time.

Each tool becomes its own page with the tool's `inputSchema` (JSON Schema)
expanded into a typed property tree. Resources are listed with their `uri`
and `mimeType`.

> Powered by `@xyd-js/mcp-uniform` — see
> [the package](https://github.com/livesession/xyd/tree/master/packages/xyd-mcp-uniform)
> for the converter spec.
