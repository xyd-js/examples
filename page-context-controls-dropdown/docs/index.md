# One menu for everything

The header dropdown groups four actions — copy, view markdown, ChatGPT,
Claude — into a single Mintlify-style menu (icon + title + description rows).

## Config

```json
{ "type": "dropdown", "appearance": "header",
  "options": { "controls": ["copy", "view-markdown", "chatgpt", "claude"] } }
```
