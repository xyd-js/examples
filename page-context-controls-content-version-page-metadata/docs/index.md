# Content-version switcher

Open a **Logs** page and use the dropdown above the TOC to switch between
the Angular and Bun variants — same doc, different runtime, one URL scheme.

The variants are `{ page, source }` virtual pages: `docs/logs.angular.md`
and `docs/logs.bun.md` served at `/docs/angular/logs` and `/docs/bun/logs`.
